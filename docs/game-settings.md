# 游戏参数设置

规则版本：`origin-1.10.0`。默认平衡数值沿用 `origin-1.9.5`；农业自然增长拆为动员型、探索型两个独立参数，默认均为每世代 0.2%。

## 使用方式

- 右上角设置按钮：查看本局实际参数、人口曲线、迁移和制度竞择公式。对局开始后全部只读。
- 右上角重新开始 → 设置下一局参数：编辑下一局草稿，保存并返回重开弹窗。输入的地图种子会保留。
- 同种子、指定种子、随机种子三种重开方式都会应用草稿。重开时同步重算相同规则下的无干预基线。
- 取消设置放弃这次编辑；关闭重开弹窗放弃尚未开局的草稿。当前对局、历史和模拟随机序列保持原样。
- 恢复默认包含迁移和制度竞择详情页里的参数。普通重开和结算页重试沿用当前参数。
- 每个参数名支持鼠标悬停或触屏长按说明。输入错误会显示范围并禁用保存，曲线保留上一有效数值。
- 自定义参数仅在本次运行中沿用；退出并重新启动游戏使用默认参数，不新增跨启动存档。

## 参数范围

百分数直接输入百分数值，例如 `1.5` 表示 `1.5%`。自然变化按每世代计算，主动改良增幅按每次成功计算。

| 参数 | 默认值 | 界面可选范围 |
| --- | --- | --- |
| 农业自然增长，动员 / 探索 | 0.2% / 0.2% | 各 0～100% |
| 工艺自然增长，动员 / 探索 | 0.2% / 1.5% | 各 0～100% |
| 两类改良成功率，动员 / 探索 | 10% / 30% | 各 0～100% |
| 成功增幅，农业 / 工艺 | 12% / 15% | 各 0.01～100% |
| 地块间学习速率 | 5% | 0～100% |
| 人口反应系数 k / 净变化上限 r | 2 / 50% | 0～10 / 0～99% |
| 移民影响力 μ | 50% | 0～100% |
| 缺粮惩罚 h / 迁移阻力 b | 4 / 0.1 | 0～20 / 0～10 |
| 迁出上限 m | 24% | 0～99% |
| 平原 / 丘陵 / 山地通行效率 | 100% / 70% / 40% | 各 1～100% |
| 用品竞争权重 w | 0.5 | 0～10 |
| 动员 / 探索竞争实力倍率 a | 1 / 0.75 | 各 0.01～10 |
| 制度替代强度 q | 20% | 0～100% |
| 保护时替代概率倍率 z | 25% | 0～100% |
| 制度替代后习惯混合 v | 20% | 0～100% |

人口变化：`ΔN/N = r × tanh[k × (s−1)]`。系数和上限可输入或拖动滑块；右侧曲线调用模拟共用函数，纵轴固定为 ±100%，虚线表示 ±r。温饱比 `s=1` 时净变化为零；上限同时作用于增长和减少，不包含迁移。

迁移详情页列出效用、迁出意愿、四邻格流量、地形限制和移民文化混合。制度竞择页列出总产出实力、最强邻格选择、替代概率、保护倍率与替代后习惯变化。均支持查看或按入口权限编辑；没有引入任意公式代码执行。
