# 富种起源当前版本玩法与获胜策略研究

> 验证资料管理：本文保留结论与复现方法；原始截图、日志、逐局记录和冻结源码仅存于 Git 忽略的 `.tmp/`，不随云端提交。历史记录路径仅供本地排查，清理后可按脚本、参数和版本重新生成。

当前单格干预版已经有可复现的通关路线。最容易执行的是：固定选中中心格 `(12,8)`，每轮按现有推荐行动；另一条手动路线是在同一格食物低于 `1.02` 时补农业，否则提升工艺。两者在本次10张地图中均获胜。现有推荐能帮助平衡选中格的农业和工艺，但不能独立承担选址、制度培养、保护和等待的全局决策。

研究对象为2026年10月9日工作区的实际文件，包含未提交修改，正式模型版本 `origin-1.8.0`。主试验为10张地图×14种策略，共140局；逐局使用正式模拟，并验证完整重放。本文的10/10表示这些指定地图上的结果，不是任意地图保证，也不是真人胜率。

## 玩家先掌握的规则

地图24×16，共384格。每轮只能选择一个地块执行一个普通行动，然后演进5世代；最多50轮、250世代，胜利可提前结束。没有金币或建造队列。可以操作任意格，不拥有固定国家。

一个地块必须同时满足“户均食物至少1”和“户均生活用品至少开局全世界人口加权均值的2倍”，其中的全部人口才算繁荣。胜利要求**繁荣人口占全世界人口至少80%，连续维持5个世代**。不是80%的地块，不是全世界平均用品翻倍，也不是80%人口采用探索制度。默认种子开局用品基准为0.5141848343，繁荣用品门槛固定为1.0283696686，整局不随世界均值上涨。

连续计数只要有一代低于80%就清零。最迟要从第246世代开始连续达标，才能在250世代内获胜。10%、30%、60%的历史里程碑会保留，但不替代胜利条件。温饱改善、探索制度存活一轮、技术向邻格传播等局部成果也是记录，没有追加行动、奖励或胜利豁免。

操作时先点地图选格，查看右侧坐标、食物、用品、制度和竞争力。`按推荐行动`会直接执行当前格的星标行动，并使用已勾选的保护；`确认所选行动`执行手选行动；`跳过本轮`不干预、不使用保护，但照样消耗一轮并演进5世代。播放时可暂停、切图层、检查数值，不能追加行动。默认选中格就是 `(12,8)`。

## 为什么人口多不一定更繁荣

设人口为N、土地软承载为K、农业效率为A、工艺效率为B、农业劳动比例为f。两项关键指标是：

```text
户均食物 = A × f / (1 + N/K)
户均用品 = B × (1-f) / (1 + N/K)
```

人口增长能增加总产出，却同时降低户均产出。K不是硬上限，超过它仍可出生和迁入。食物高于1促进自然增长，低于1造成自然减少，每世代自然增减幅度小于6%；用品不直接改变出生率。农业多出的粮食会逐渐被新增人口消耗，所以把农业一路堆高，不等于永久改善每个人的生活。

提升工艺直接增加用品，也会让邻居觉得这里更适合生活。迁移只比较上下左右四邻格：用品越好越有吸引力，缺粮会受到强烈惩罚；生活差超过0.10才产生迁移。一个来源每代实际迁出小于其人口的8%，并受地形折减。迁入会增加拥挤，也会按实际流量把当地务农比例向迁入者的习惯拉近；方向不一定是更多务农。没有粮食跨格调拨、共享仓库或地区共同生产。

因此，一格用品特别高，可能吸来人口并使食物不足。默认地图的中心格只做工艺，250世代时世界平均用品达到27.50，远超1.028的门槛，仍有28.41%人口属于“用品达标但缺粮”，最终繁荣仅66.96%。平均数不能替代逐格同时达标。

## 五种行动分别解决什么问题

| 行动 | 立即效果 | 适合的判断 |
|---|---|---|
| 农艺改良 | 本格农业效率×1.12 | 食物不足或预留一点余量；不直接挤占制物劳动，但后续会促进人口增长 |
| 工艺改良 | 本格工艺效率×1.15 | 温饱有保障而用品不足，或继续建设能向外传授工艺的核心 |
| 更多务农 | 农业劳动比例加10个百分点 | 急需食物，且用品仍有足够余量；会立即减少用品生产 |
| 更多制物 | 农业劳动比例减10个百分点 | 确认粮食余量足够，愿意用食物换用品；临近温饱线时风险较大 |
| 制度试验 | 本格改为探索型 | 在剩余时间较多时建立持续工艺增长来源；没有即时技术或财富赠送 |

务农比例限制在25%—85%。以60%务农为例，改为50%时，在人口尚未变化的瞬间，食物只剩原来的5/6；原来食物1.05会降至0.875。需要原来至少1.20才刚好维持温饱。反过来，从60%改为70%务农，用品会立即减少25%。这解释了为什么小幅缺粮时，直接改良农艺通常比大幅调整劳动分配更容易掌握。

这些是操作瞬间的比较；之后人口、迁移、习惯混合和技术传播会继续改变结果。本次有效策略最终只使用了农业、工艺、制度和跳过；这不能证明两种劳动调整永远无用，只说明无需它们也能通关。未单独优化劳动调整路线。

## 技术和制度怎样影响整个地图

所有格子的农业每世代增长0.2%；动员型工艺增长0.2%，探索型工艺增长1.5%。每代自然增长后，农业与工艺分别向四邻格中最高的技术学习差距的5%，同步执行，一代不会连续传两格。技术学习不消耗对方技术，也不要求相同制度。

这让重复建设少数核心有价值：提升不只留在一格，而是逐步向外传播。已经学到的技术在制度被替代后仍保留。探索型可以只有少量人口，却给周边提供技术；制度占比不需要达到80%。默认地图中心推荐路线获胜时，探索型人口已经为0，仍符合正式胜利规则。

制度竞争使用每格总产出：`竞争力 = 制度系数 × (食物总量 + 0.5 × 用品总量)`。动员型系数1，探索型0.75；所以本格改为探索型，会立即降低四分之一竞争力，然后才依靠工艺增长逐渐积累优势。

每格只看**竞争力最强的那个邻格**。它必须比本格强、且制度不同，才有概率替代本格；不是多数邻居投票，也不是全地区合力。替代概率为 `0.2 × (强者竞争力-本格竞争力)/(两者竞争力之和)`。替代不杀伤人口、不删除技术，但会把务农比例向来源格靠近20%。最强邻格与本格同制度时，较弱的异制度邻格不会获得本代替代机会。

培养探索制度时，应检查改制后的竞争力，也就是当前动员格显示值的75%，再与邻格比较。人口多、经济强、有相同制度强邻居支撑的地块较有利。弱小孤立的山地格紧贴强势动员平原，可能难以站稳。这个判断针对制度存续；不能直接拿来断言它不适合当技术核心。

## 地形和地区如何用于选址

| 地形 | 软承载倍率 | 迁移效率 | 策略含义 |
|---|---:|---:|---|
| 平原 | 1.50 | 100% | 通常容纳较多人口，补短板能影响较多人；也容易发生较快迁移 |
| 丘陵 | 1.00 | 70% | 容量与迁移居中 |
| 山地 | 0.50 | 40% | 同样人口更拥挤，迁移较慢；技术学习和制度邻接没有地形阻断 |

迁移跨边取两端较低的效率。开局人口会随实际容量一起缩放，因此不能认为山地开局必定缺粮；容量低主要影响此后的拥挤反馈。默认图为262格平原、69格丘陵、53格山地，无河流、河岸加成或传播屏障。

地区名称只是初始特征和定位信息，不是永久加成或政治单位。丰禾乡开局农业较好、有少量粮食余裕；百工镇工艺较好、务农较少；万家聚容量和人口较多，略有温饱压力；疏居地人口和生产基础较低。比较时仍应看具体地形、当期人口与指标，地区边界不阻止任何传播。

**选择技术核心**优先考虑传播位置和能否持续补足两类生产。固定中心格有四个邻居，到地图各处的距离比较均衡，玩家也无需反复查找。默认中心格实际是山地、开局约11.32户，依然能作为成功技术核心；本试验没有把中心性、山地减慢迁移等因素逐项拆开做因果消融，不能说山地普遍优于平原。

**选择制度试验格**则优先考虑改制后的相对竞争力，并照顾地图上缺少探索来源的区域。**选择后期补短板格**应查看当地到底缺什么，以及它涉及多少人口；最后20%不是固定的20%格子。

## 可以直接照做的前中后期打法

### 最省操作的路线

开局保留默认中心格 `(12,8)`，不勾保护，每一轮都点击 `按推荐行动`，等本轮结束再继续，直到胜利。不要把这条路线改成每轮换一格。在测试的10张地图中，此路线全部获胜，首胜世代178—209；默认地图为第41轮、第201世代。默认图共做33次工艺、8次农艺，没有改制度或调整习惯。

推荐按钮本身没有选出这个位置。这是一条“固定中心选址＋现有局部推荐”的组合策略；结果不代表任意选格后连续点击推荐都能获胜。

### 手动兼顾农工的路线

始终操作 `(12,8)`：**当详情中的食物低于1.020，执行农艺改良；否则执行工艺改良。**不改习惯、不改制度、不使用保护、不跳过。这个1.02是研究策略的判断门槛，没有改动游戏胜利门槛或任何参数。10张测试地图全胜，首胜世代175—208，中位数197.5；相较中心推荐，有7张更早、3张更晚，不能称为普遍更优。

| 阶段 | 操作与观察 | 默认地图参考 |
|---|---|---|
| 前期 第1—10轮 | 按上述同一规则积累核心技术，接受繁荣暂时很低；不要因为人口少或山地就搬走核心 | 第1轮农艺，第2—8轮工艺，第9轮农艺；第50世代繁荣约2.02% |
| 中期 第11—30轮 | 继续补农业与提升工艺，查看邻格学习和全图缺用品占比；不追求把全图制度染成一种颜色 | 第100世代繁荣20.14%，第150世代57.43% |
| 后期 第31轮起 | 保持同一规则，避免突然改习惯打破粮食余量；看连续达标计数 | 第175世代70.00%；第191—195世代连续达标，第39轮获胜 |

默认种子20261002的农艺轮次是 **1、9、13、17、20、24、27、30、33、36、39**，其他轮次都是工艺。共11次农艺、28次工艺。第191—195世代繁荣分别为80.0535%、80.4655%、80.7300%、81.0920%、80.8589%。达到80%时不必凑满剩余轮数，游戏会提前结算。

### 想体验制度培养的进阶路线

前30轮优先把有经济基础、改制后相对强、又远离现有探索核心的动员格改为探索型。观察是否被替代，必要时重新建立；不要假设一次试验就永久成功。第31轮后停止持续铺制度，转向用品将要达标的有粮地块，或用品充足但缺粮的地块，补上对应生产短板。

本次把这条思路写成独立研究策略：前30轮在合法格中最大化“人口×相对竞争力系数的四次方×空间分散系数”；空间分散系数为到最近探索格的曼哈顿距离除以5，上限1。后期沿用现有 `OriginWinability` 均衡策略的四种经济行动比较。它不查看未来随机数，没有使用回滚或未来模拟搜索。全部10图获胜，首胜151—201世代，中位数180；默认图第178世代获胜。

这组结果验证的是上面的确定性选址算法。玩家凭目测“挑强格、尽量分散”不等同于逐轮执行该算法，不能直接继承10/10结果。默认地图的36轮确切操作已放入[逐轮操作表](default-actions.md)，可以照表体验。它比中心路线更需要频繁换格和检查邻居，适合愿意探索机制的玩家。

## 保护怎样安排以及何时跳过

全局只有3次保护，每次与普通行动一起确认，只作用于同一格，持续之后的5次制度竞争。替代概率乘0.25，仍可能失败。保护不提高产出、不拦迁移、不降低拥挤，也不保护邻格。已经是探索型的格子不能再次用制度试验续保护，但可以在合法的工艺或农业行动上附加保护。跳过不能附加保护。

中心农工路线不依赖探索制度，所以本次全部保留3次保护仍获胜。制度路线可以把保护留给刚改制、最强邻居是更强动员格、且值得长期维持的核心。如果改制后已不弱于最强邻格，或最强邻格本来就是探索型，当下没有需要保护阻挡的那种竞争；仍需在以后回合重新观察。

保护不是“越早用完越好”的通关加速器。均衡策略的前3轮固定附加保护，与无保护版本均为10/10，但通关中位数从200变为206.5世代；默认图快1代，种子418917反而慢20代。分散制度策略的危险时保护也是10/10，10图中7图同代获胜、1图更快、2图更慢。它确实降低受保护格的局部替代概率，但会改变后续世界轨迹，不能由局部收益推导整局一定更快。这些小样本没有找到最优的三次使用时机。

跳过适合让已经建立的增长和传播继续工作，或在繁荣达标后等待连续计数。它不储存行动机会，也不停止人口变化。不要只因世界平均用品很高就连续跳过，应查看缺粮、缺用品和连续达标情况。

实证上，分散制度策略只执行前30次制度试验，之后全跳过，也有10/10，首胜151—243世代；默认图179世代获胜，比继续补短板晚1代；种子1晚43代。另一条不同的“强格制度培养30轮后全跳过”探索实验在种子1失败，峰值76.51%。因此，“30轮后能跳过”取决于此前形成的局面，不是统一通关规则。前者最多用了约49轮，已很靠近截止时间，继续补短板通常给玩家更多余量。

### 怎样把选址和行动区分开

中心对照全部固定 `(12,8)`；逐行对照从 `(1,1)`、`(2,1)`依次扫描，50轮最多访问前两行和第三行前两格；四核心对照在开局的四个象限各取竞争力最高格，之后固定按左上、右上、左下、右下轮换，同分取行优先首格。它不是每轮重新挑最强格。每一组的工艺版与推荐版使用完全相同的坐标安排。

中心组从0/10变成10/10，是在相同选址下替换行动规则的实际改善；推荐在10局中做了310次工艺和88次农艺。逐行组两版逐轮行动和逐世代轨迹完全一致，均3/10。四核心组两版也完全一致，均10/10，所有行动都仍是工艺。后两组胜率差异来自选址安排，不能说“推荐把四核心救活了”。逐行只覆盖地图上方，也不能将它的失败泛化为所有分散策略都无效。

制度组的强格评分为 `人口 × min(1, 改制后竞争力/最强邻格竞争力)^4`，这是存续倾向的启发式分数，并非正式概率或保证。均衡组前30轮与其相同，随后按四种经济行动的即时人口加权改善选择格子与行动；对剩余超过25世代的探索格工艺提升保留现有策略的小额偏好。分散制度组只修改前30轮的选址评分，后期逻辑相同。保护组保持相同选择规则，但保护改变局势后，之后的实际选择可以不同，结果反映整套策略效果。

### 成功和失败说明了什么

默认无干预68.91%，强格持续改制度最高76.44%。后者到250世代仅0.97%人口还单独缺用品，却有24.75%人口用品达标但缺粮：继续铺制度没有补上最后的温饱短板。改为第31轮后补经济短板，同一前30轮路径的均衡策略在201世代获胜。这支持及时转换目标，不能由探索增长快推导“50轮全改制度最好”。

种子314188的逐行工艺策略最终峰值81.0035%，但第247世代才越过80%，在250世代只累计4次连续达标，正式结果为失败。它不能被“最高繁荣超过80%”的指标误判为成功。

自然演进在种子418917、523646、628375本来就会获胜，分别是218、228、239世代。评价玩家作用必须与同种子无干预比较。主试验没有把自然胜利全部归功于某种操作，也没有用历史报告或单元测试通过数代替当前通关证据。

## 现有推荐的帮助与局限

独立核对确认：默认开局384格全部推荐工艺；另外9张地图开局也都是384格工艺。推荐从当前选格的五种合法主行动中，比较最多两轮、当前即10世代的本地预测。人口被冻结，只外推本地农业与制度对应的工艺增长；得分为截断到1的温饱完成度八次方乘用品完成度二次方。它不选择地块，不比较跳过，也不决定保护时机。

这里还有一个结构性限制：10世代内改探索制度相对继续动员型的工艺优势是 `(1.015/1.002)^10 = 1.13758`，小于直接工艺改良的1.15。约到第11世代才反超。在推荐模型内，农业和人口预测相同，得分又随用品单调增加，所以按当前默认参数，合法的制度试验不会胜过工艺改良；同分时工艺排在前面。不是仅开局碰巧没有制度推荐，而是这一短期评分无法主动提出制度培养路线。

推荐的实际价值是帮助玩家在已选地块上发现直接短板，尤其是工艺核心发展后需要补农业的时刻。其缺口包括：

- 出生、拥挤、迁移及习惯混合会改变预测分母和劳动分配。
- 四邻格技术外溢和地图覆盖决定局部建设对全局的影响。
- 探索制度需要超过10世代的积累，也可能在积累前被竞争替代。
- 胜利按人口权重和连续5代判断，局部完成度不等于全图新增繁荣人口。
- 达标后的粮食余量在截断评分中没有额外价值；所有方案同分时优先工艺，也不会建议等待。
- 保护只参与合法性校验，没有预测它对制度存续的帮助。

因此，**它是有用的局部行动助手，在明确固定中心选址后甚至足以支撑本次全部测试图通关；它还不是能独立指导任意局面获胜的全局策略系统。**本次结果既不支持把它判为无效，也不支持给它通关保证。

以后若改进，可以先分成“推荐位置”和“推荐动作”两个结果；加入跳过候选；把预测延长到足以看见制度积累的时间，并纳入正式人口、迁移、技术和竞争过程；用新增繁荣人口、温饱余量、连续达标和截止时间评价；保护则另算局部存续收益。评估时继续保持相同选址的动作对照和未参与调参的地图，避免只在默认种子上优化。不应通过读取未来随机数生成看似稳健的玩家建议。本次未实现任何推荐改动。
